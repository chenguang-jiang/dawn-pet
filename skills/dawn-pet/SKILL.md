# Dawn Pet

Dawn Pet 现在是 DawnVibe 首页的灰白雪纳瑞，以用户选定的简化手绘版为正式形象。角色一致性优先于场景细节。

## 开始前

- 阅读 [identity.md](references/identity.md)，并查看正式锚点 [dawn-pet-anchor.png](assets/identity/dawn-pet-anchor.png)。每次生成都将它作为第一身份参考图传入 ImageGen；不能只用文字描述代替。
- 按下表自动判别资产类型，用一句话声明后继续。流程图解额外读取 [flow-diagram.md](references/flow-diagram.md)。
- 阅读 [visual-system.md](references/visual-system.md)，按 [prompt-template.md](references/prompt-template.md) 组织提示词，完成后按 [qa-checklist.md](references/qa-checklist.md) 检查。

## 自动判别资产类型

| 内容结构 | 类型与规格 |
|---|---|
| 头像、logo、主视觉，无动作叙事 | 头像或主视觉：白底，单角色，轮廓清楚 |
| 几种姿势或动作集合 | 动作设定图：横向白底，最多三个互不遮挡的姿势 |
| 一个概念、动作或比喻，没有先后关系 | 正文场景配图：默认 16:9，一个动作、一个主要道具 |
| ≥2 个有序步骤、时序连接、状态迁移、条件分支或循环 | 流程图解：同一只狗逐节点演出动作，稀疏箭头连接，节点下短标签 |
| 已有图，只改一部分 | 局部编辑：只改点名部分，其余保持不变 |

**自动降级**：主线节点超过 6，或涉及精确数值、表格、代码、多泳道并发时，使用 mermaid；可另配 3–5 节点的 Dawn Pet 意境封面，不能用插画冒充精确图。

## 锁定身份

- 灰白雪纳瑞幼犬，头部偏大、身体紧凑，四肢短而有重量感；保留犬类头身结构。
- 两只自然下折的三角耳；奶白浓眉、脸颊、胡子与胸前毛；灰色背部和耳朵。
- 两只棕色眼睛，有黑色瞳孔和少量高光；黑鼻子、小而自然的嘴。
- 鼠尾草绿色项圈配小黄铜色扣，是固定身份特征。
- 短毛笔触与略抖黑色轮廓，简化色块；按锚点保持毛色分区和比例。
- 不沿用旧黑色小怪物的身份规则：没有一体黑团、白色点眼或橙红肚标。

## 表达性格

认真、友善、好奇，做事略有笨拙。优先用歪头、抬爪、坐等、鼻子推物、前爪抱箱子等姿势表达。可短暂坐靠后腿操作道具，但仍是狗爪，不能变成人手、长手臂或直立人形。不要依靠夸张表情或额外配饰卖萌。

## 生成与交付

1. 使用内置 ImageGen，正式锚点为第一身份参考；其他图片仅用于道具、姿势或构图，不能覆盖身份。
2. 默认采用简化手绘风，保留毛色、耳形、眉毛胡子、棕眼与绿色项圈。不要自行切回写实毛发或旧怪物。
3. 白底、留白、稀疏细线道具。流程图按节点语义选择狗能做出的动作，标签放在角色之外。
4. 查看生成结果：先检查犬类轮廓和毛色，再检查面部、项圈、爪子和道具。失败时针对不一致处修改，不重复扩写场景。
5. 预览图可保留在生成目录并内联展示；项目使用的最终图保存到 `assets/dawn-pet/<topic-slug>/`，使用可读文件名，并交付实际路径。
