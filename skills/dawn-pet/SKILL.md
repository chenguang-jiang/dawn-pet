# Dawn Pet

Dawn Pet 现在是 DawnVibe 首页的灰白雪纳瑞，以用户选定的简化手绘版为正式形象。角色一致性优先于场景细节；固定的是角色外形，不是姿势、道具或构图。

## 开始前

- 阅读 [identity.md](references/identity.md)，并查看正式锚点 [dawn-pet-anchor.png](assets/identity/dawn-pet-anchor.png)。每次生成都将它作为第一身份参考图传入 ImageGen；不能只用文字描述代替。
- 按下表自动判别资产类型，用一句话声明后继续。流程图解额外读取 [flow-diagram.md](references/flow-diagram.md)。
- 阅读 [visual-system.md](references/visual-system.md)，按 [prompt-template.md](references/prompt-template.md) 组织提示词，完成后按 [qa-checklist.md](references/qa-checklist.md) 检查。

## 自动判别资产类型

| 内容结构 | 类型与规格 |
|---|---|
| 头像、logo、主视觉，无动作叙事 | 头像或主视觉：白底，单角色，轮廓清楚 |
| 几种姿势或动作集合 | 动作设定图：横向白底，最多三个互不遮挡的姿势 |
| 一个概念、动作或比喻，没有先后关系 | 正文场景配图：默认 16:9，一个动作、一个主要道具 |
| ≥2 个有序步骤、时序连接、状态迁移、条件分支或循环 | 流程图解：同一只狗逐节点演出动作，稀疏箭头连接，节点下短标签 |
| 已有图，只改一部分 | 局部编辑：只改点名部分，其余保持不变 |

**自动降级**：主线节点超过 6，或涉及精确数值、表格、代码、多泳道并发时，使用 mermaid；可另配 3–5 节点的 Dawn Pet 意境封面，不能用插画冒充精确图。

## 锁定身份

- 灰白雪纳瑞幼犬，头部偏大、身体紧凑，四肢短而有重量感；保留犬类头身结构。
- 两只自然下折的三角耳；奶白浓眉、脸颊、胡子与胸前毛；灰色背部和耳朵。
- 两只棕色眼睛，有黑色瞳孔和少量高光；黑鼻子、小而自然的嘴。
- 鼠尾草绿色项圈配小黄铜色扣，是固定身份特征。
- 短毛笔触与略抖黑色轮廓，简化色块；按锚点保持毛色分区和比例。
- 不沿用旧黑色小怪物的身份规则：没有一体黑团、白色点眼或橙红肚标。

## 场景与数量

- 每次先从用户内容中提取要表达的具体关系或动作，再选择姿势、主要道具、视角和布局。文档只是使用场合，不能自动转成“狗坐在书旁”；读取、知识、学习等词也不能直接决定画书。
- 新场景默认重新创作；只有用户明确要求改已有图时才按局部编辑处理。传入锚点只用于身份和画风，不沿用它的坐姿、抬爪、朝向或居中布局。
- 多张独立配图先列出简短场景清单，每张包含“内容含义 → 动作 + 道具 + 姿态/视角”。在语义允许时，让不同图在动作、身体姿态、视角、空间关系中至少两项有明显区别，不能只换书页、图标或小道具。用户明确要求同构图对比时保留其要求。
- 未指定数量时，默认生成 **3 张独立图片**，分别承担不同的表达任务；“几个示例”也默认三张。根据内容安排主题概览、核心概念、结果或应用场景等，不强制每次使用同一套三段结构。
- **关键流程额外加图**：扫描内容中的关键操作、状态迁移、决策或先后依赖，每个需要单独解释的关键流程追加一张流程图解，不能占用基础三张名额。同一流程的重复描述合并；复杂流程仍遵守 mermaid 降级规则，精确流程可交给 mermaid，并按需附主线意境图，不用不准确的插画凑数。
- **重大里程碑、重要事件、强调内容可追加配图**：判断是否有独立的时间转折、成果、影响或理解难点。配图能帮助理解、记忆或突出重点时追加，已经被现有配图充分覆盖则不重复；不因每个加粗词或普通小标题机械加图，也不虚构事件。
- 生成前简短列出总数及用途，例如“基础 3 张 + 关键流程 1 张 + 里程碑 1 张，共 5 张”，随后执行。没有额外内容就是三张；不把三张设为总数上限。
- 用户明确指定总数 N 张时，以 N 张为准，在该数量内优先覆盖关键流程与重点，不擅自超出；若明确说“另外加图”则按追加数量计算。局部编辑按用户指定的目标图处理，不自动扩成三张。明确要求合在一张的动作设定图或流程图时，按一张交付；一张流程图中的多个节点不算多张独立图片。
- 每张独立图片单独调用 ImageGen，并交付独立文件；动作设定图最多三姿势只是单张图的布局限制，不是整批输出的数量上限。
- 新主题不把上一张场景图自动当作参考图；有角色锚点即可。用户提供的重复结果可用于说明应避免的动作与布局，不默认作为编辑底图。

## 表达性格

认真、友善、好奇，做事略有笨拙。按语义选择四足行走、前倾推动、低头嗅查、伸爪触发、趴卧等待、回头观察或抱物等动作，不默认坐着抬爪。可短暂坐靠后腿操作道具，但仍是狗爪，不能变成人手、长手臂或直立人形。不要依靠夸张表情或额外配饰卖萌。

## 生成与交付

1. 使用内置 ImageGen，正式锚点为第一身份参考；其他图片仅用于道具、姿势或构图，不能覆盖身份。
2. 默认采用简化手绘风，保留毛色、耳形、眉毛胡子、棕眼与绿色项圈。不要自行切回写实毛发或旧怪物。
3. 提示词必须写明这张图的动作、姿态、视角和空间关系，按场景重绘而非复刻锚点姿势。白底、留白、稀疏细线道具。流程图按节点语义选择狗能做出的动作，标签放在角色之外。
4. 查看生成结果：先检查是否表达本次内容、图片数量和场景差异，再检查犬类轮廓、毛色、面部、项圈、爪子和道具。若只重复锚点或上一张的动作与布局，重写动作与构图后重新生成。失败时针对不一致处修改，不重复扩写场景。
5. 预览图可保留在生成目录并内联展示；项目使用的最终图保存到 `assets/dawn-pet/<topic-slug>/`，使用可读文件名，并交付实际路径。
