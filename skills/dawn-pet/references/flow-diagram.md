# Dawn Pet 流程图解指南

## 整篇配图中的数量

整篇文档未指定数量时，基础三张之外，每个独立关键流程额外配一张流程图解。同一流程合并重复描述，不为每个步骤单独加一张。单独明确要求“一张流程图”时生成一张；用户指定全批总数时，流程图在指定总数内安排。复杂流程使用 mermaid，不能为满足数量而生成不准确的图。

## 自动识别信号

有序步骤、时序连接、状态迁移、条件分支、循环或重试，都按流程处理。先用一句话声明类型，再取 3–5 个主线节点。6 个节点是上限；精确数值、表格、代码、接口字段、多泳道并发或更复杂流程交给 mermaid，可另配主线意境封面。

## 节点语义 → 动作映射表

每个节点是正式锚点中的同一只灰白雪纳瑞。折耳、奶白眉毛胡子、棕眼、绿色项圈和犬类比例一致，姿态、视角和布局按各节点语义选择。下面是可选映射示例，不是关键词触发的固定画面。

| 节点语义 | 狗狗动作 | 主要道具 |
|---|---|---|
| 开始、触发 | 坐着用一只前爪按大按钮 | 按钮 |
| 发送、请求 | 用鼻子把信封推向前方 | 信封 |
| 接收 | 坐着用前爪接住滑来的箱子 | 箱子 |
| 处理、计算 | 坐靠后腿，用前爪按大键盘 | 键盘 |
| 等待、异步 | 坐在沙漏旁，歪头耐心等待 | 沙漏 |
| 校验、验证 | 凑近放大镜检查箱子 | 置于支架上的放大镜 |
| 授权、同意 | 在大纸上按一下爪印 | 纸 |
| 连接、对接 | 用前爪把两个插头推到一起 | 两个插头 |
| 传输、搬运 | 四足走路，用嘴叼文件袋 | 文件袋 |
| 存储、写入 | 用鼻子把箱子推进柜子 | 柜子与箱子 |
| 读取、查询 | 按对象设计：查询记录可用鼻子从文件匣中拨出卡片；只有阅读书籍时才翻书 | 文件匣与卡片，或内容需要的对象 |
| 分支、判断 | 坐在岔路口，歪头左右看 | 路牌 |
| 成功、完成 | 稳稳坐好，抬一只前爪 | 小对勾旗 |
| 失败、错误 | 坐倒在歪斜的箱子旁，一只爪子悬着 | 歪斜箱子 |
| 重试 | 从坐倒姿势重新撑起，前爪扶回箱子 | 同一个箱子 |
| 循环 | 绕箱子走，再用鼻子推动 | 箱子 |
| 合并、汇总 | 用鼻子将小箱子推到一起 | 小箱子组 |
| 通知、告警 | 用前爪按响小铃 | 铃铛 |

没有对应项时，按“认真、略笨拙、一个主要道具”选择狗能完成的动作。不生成手指、人手或人形站姿，不用复杂图标取代动作。

## 布局、箭头与标签

- 顺序流程默认一行 3–5 节点，左到右；循环默认 3–4 节点，回环箭头走外侧；分支可用上方一节点、下方两节点。
- 每张图只选一种布局。角色与道具不重叠，箭头方向清楚、不交叉，节点间保留明显空隙。
- 标签为节点语义，中文最多四字或英文最多两词，黑色手写感，放在节点正下方、狗与道具之外。
- 不放标题、图例、边框、水印或序号圆圈。
- 白底，角色保持灰白毛色、棕眼和绿色项圈；道具、箭头、标签为稀疏细黑线。不能沿用旧黑团或橙红肚标。

## 提示词与 mermaid 协作

使用 [prompt-template.md](prompt-template.md) 的主模板加流程图解模板，每次都传正式锚点作为第一身份参考。例：发起连接（前爪按按钮）→ 登录授权（纸上按爪印）→ 校验通过（凑近放大镜）→ 开始读取（从文件匣拨出记录卡）。

技术文章用 mermaid 承载完整节点、条件与字段；Dawn Pet 插画只画主线意境，两者节点命名对齐。生成后检查每个节点是同一只狗、爪子自然、箭头正确、标签清楚；只修正有问题的节点或连接。
