# Dawn Pet 视觉系统

## 风格与色彩

默认使用正式锚点的简化手绘风：略抖黑色轮廓，灰色与奶白色块，少量短毛笔触，柔和且有手绘感。棕色只用于眼睛，鼠尾草绿与黄铜色用于项圈。背景纯白，避免渐变、光泽、复杂阴影和繁密毛发。需要透明素材时使用真实透明背景并保留 alpha。

道具、环境和箭头使用稀疏、清晰的细黑线，默认不额外上色。犬类本体保留灰白色与项圈颜色，不能套用旧版纯黑角色的配色限制。

## 构图

- **头像或主视觉**：单只狗，轮廓清楚，裁切不能损伤耳朵、眉毛胡子等识别特征。
- **动作设定图**：横向白底，最多三个姿势，彼此留出空隙，同一只狗的身体比例和项圈一致。
- **正文场景配图**：默认 16:9，一个核心动作、一个主要道具，保留充足白边。
- **流程图解**：默认横向 3–5 节点，每节点一只相同的狗做不同动作，节点之间用细线箭头连接；标签位于节点下方，不压住角色。
- **局部编辑**：保留未被点名修改的身份、构图、笔触和背景。

非流程图默认无文字、标签、边框和水印。流程图只允许节点下方的短标签。可爱来自动作与比例，避免用大眼、高光或装饰堆砌表情。
